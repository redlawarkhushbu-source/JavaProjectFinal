# शेत समर्थन | Shet Samarthan 🌱

### AI-Powered Smart Agriculture Platform & 3D Farm Simulator

**Tagline:** Smart Farming Together · समृद्ध शेती, उज्ज्वल भविष्य

## 🌾 About the Project

**शेत समर्थन (Shet Samarthan)** is an AI-powered smart agriculture platform designed to support Indian farmers through intelligent crop analysis, interactive 3D farm visualization, weather forecasting, agricultural resource discovery, and multilingual voice assistance.

The platform combines artificial intelligence, modern web development, 3D graphics, and agricultural information to provide farmers with a unified digital farming experience.

## ✨ Key Features

### 1. AI Crop Disease Diagnosis
- Analyze uploaded crop and leaf images using a deep-learning model.
- Identify potential plant diseases based on model predictions.
- Display classification results and confidence scores.
- Provide relevant disease prevention and treatment guidance.

### 2. Interactive 3D Farm Simulator
- Explore farmland through an interactive 3D environment.
- Visualize supported crops, including tomato, wheat, rice, cotton, and sugarcane.
- Represent different soil types, including black soil, red soil, alluvial soil, and sandy soil.
- Explore visual simulations of rainfall, drought stress, and crop-related conditions.

### 3. Weather & Agricultural Advisory
- Access weather information for selected locations.
- View temperature, humidity, rainfall probability, and forecast information when available.
- Provide weather-based agricultural advisories.
- Support informed decisions regarding irrigation, spraying, and crop care.

### 4. Nearby Agricultural Suppliers
- Locate agricultural supply stores using map-based navigation.
- Discover nearby sources of seeds, fertilizers, organic manure, and crop-care products.
- View available supplier information and directions where supported by the data source.

### 5. Multilingual Voice Assistant
- Interact with the platform using voice commands.
- Support Marathi (मराठी), Hindi (हिंदी), and English.
- Provide speech recognition and spoken responses using supported browser capabilities.
- Improve accessibility for users who prefer voice-based interaction.

### 6. Farmer Dashboard
- Access farm information from a centralized dashboard.
- View crop-related information and weather updates.
- Navigate to diagnosis, farm simulation, weather, and supplier modules.
- Access relevant agricultural advisories and application features.

### 7. User Authentication & Farm Management
- Provide user registration and login.
- Manage farmer profiles and farm information.
- Store application data through the backend and database.
- Support authenticated access to protected application features.

## 🏗️ System Architecture

Shet Samarthan follows a full-stack architecture with a React frontend and a Java Spring Boot backend.

- **Frontend:** Provides the user interface, interactive dashboards, image uploads, 3D visualization, maps, and voice interactions.
- **Backend:** Handles application APIs, business logic, authentication, data processing, and external service integrations.
- **Database:** PostgreSQL stores application data and supported farmer and farm records.
- **AI Integration:** Processes crop images through the configured disease-classification model.
- **External Services:** Supply weather information and mapping capabilities through configured providers.

## 🎨 Design & Accessibility

The platform uses a nature-inspired visual identity with a modern agricultural technology interface.

- Deep forest green and natural green as primary brand colors.
- Clean layouts with responsive cards and intuitive navigation.
- Manrope and Inter typography, with Noto Sans Devanagari for Marathi and Hindi.
- Light application theme and an immersive dark 3D farm environment.
- Responsive layouts for desktop, tablet, and mobile.
- Multilingual interaction designed to improve accessibility.

## 🎯 Project Objective

The objective of Shet Samarthan is to make agricultural technology more accessible by combining crop disease analysis, 3D farm visualization, weather intelligence, local agricultural resources, and multilingual assistance in one platform.
